# Reisesøk

Reisesøk for hele Norge: reiseplan med alle bytter (buss, tog, trikk, T-bane, ferje, hurtigbåt og innenriksfly), avgangstavle for alle stopp og ferjekaier, og flytavle for Avinors lufthavner og Torp.

Data: [Entur](https://developer.entur.org) (NLOD) og Avinor via [allemannsdata.com](https://allemannsdata.com/wiki/kilder/avinor/). Siden kjører i nettleseren og lagrer ingenting utenfor den.
